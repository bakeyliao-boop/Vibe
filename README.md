# Vibe Mock

一款面向小范围朋友共同使用的内容收藏与回溯产品 Mock。

当前原型将同一批分享内容按地点、类型与分享人三种视角重新组织；选中资源后，提供明确的原内容入口。

## 体验

本项目是无需构建步骤的纯前端单页，可直接通过 GitHub Pages 发布。

在线体验：[Vibe Mock](https://bakeyliao-boop.github.io/Vibe/)。

上一版 `8163f7d` 补齐了从空相册开始、内容背面与改错、移除 / 撤销、邀请双方和只读 / 成员角色演示，以及依据已有时间、来源和地点的回顾线索。搜索、分组与相册使用同一份可更新数据。这些流程继续保留，保存起点由新分享承接替代。完整状态与历史检查见 [ADR-0014](docs/adr/0014-prebuild-mock-completeness.md)。

默认打开示例相册；可在“一起留着”或页面外的“体验场景”切到自己的空相册。两本相册分别保存在当前浏览器的 `localStorage`，刷新后可继续，恢复示例不会清空自己的相册。这是方便重复体验的两套本机数据，不是已确定的生产私人 / 多人空间模型。存储不可用时保留输入和旧数据，损坏记录需确认后才能重置；见 [ADR-0015](docs/adr/0015-local-mock-data-and-capture.md)。

`8163f7d` 的粘贴陌生链接只读取链接和用户提供的文字，不联网提取作品。已知小红书样例可使用预置资料，界面明确标识“未联网解析”。新入口的来源分享演示沿用公开小红书样例，抖音使用明确合成内容并指向本站分享演示，不使用本机私有研究样本；来源界面只是概念示意，不能代表真实平台的按钮或传入字段。字段搜索不使用 LLM；真实平台解析、iPhone 系统分享接入、账户、服务端权限和云同步仍未实现。邀请也只在同一浏览器切换双方视角，不发送真实邀请；见 [ADR-0016](docs/adr/0016-invitation-and-role-demo.md)。
