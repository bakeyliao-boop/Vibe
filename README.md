# Vibe Mock

一款面向小范围朋友共同使用的内容收藏与回溯产品 Mock。

当前原型将同一批分享内容按地点、类型与分享人三种视角重新组织；选中资源后，提供明确的原内容入口。

## 体验

本项目是无需构建步骤的纯前端单页，可直接通过 GitHub Pages 发布。

在线体验：[Vibe Mock](https://bakeyliao-boop.github.io/Vibe/)。

当前是使用 13 条预置小红书样例的交互 Mock。地点、类型、分享人和慢节奏记忆浮现已上线。

本轮同页查找与稳定的查看全部已上线，产品代码基线为 [`69edcf0`](https://github.com/bakeyliao-boop/Vibe/commit/69edcf0)：顶部“找一条”首次搜索全部 13 条；分组“查看全部”展开该组全部内容；支持根据现有标题、地点、类型、分享人等字段组合查找，选中后打开原文。查找期间暂停自动变化，返回相册与再次查找保留相应上下文。检查覆盖 Chrome 模拟 320 / 375 / 390 / 393px、明暗主题、键盘和减少动态；线上文件已与本地逐字节核对一致，真机专项和目标小组测试仍待完成。实现范围、检查与发布证据见 [ADR-0008](docs/adr/0008-browse-and-retrieval.md)。

搜索仅针对预置样例的已有字段，不使用 LLM；真实导入、收藏持久化、多人账户和同步仍未实现。文档分别记录决策、实施和验证状态，避免把已讨论方向当成已交付能力。
