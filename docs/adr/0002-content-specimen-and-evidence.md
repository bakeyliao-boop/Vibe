# ADR-0002：以可辨认内容与可追溯依据构成标本

- 决策状态：已接受
- 实施状态：预置样例部分实现；自动采集与归档未实现
- 验证状态：有真实素材展示；没有平台批量采集成功率结果
- 建档日期：2026-09-12（历史回填）
- 决策日期：未记录；不晚于 2026-08-12 首次原型提交
- 类型：产品 / 数据
- 路线关联：[R2、R3](../../ROADMAP.md)

## 问题与依据

用户能提供的主要是分享链接，至多包含封面。只靠这些素材无法支撑生成式剧情，也不能保证识别所有地点。用户接受链接未来可能无法打开，只要保留标题、封面和关键信息，能帮助回查原文或相似内容。

## 候选与决策

- 只留 URL：信息太少，用户难凭视觉和印象找回。
- 自动生成剧情、主题图或未经确认的地点：超过当前输入可支持的事实。
- **采用：保留实际取得的标题、封面、原始出处；在有记录时显示分享者、时间和分类依据。** 缺失信息显式标记，不填造。

分享文案、原链接及平台内容标识等未来输入保存方案由 [ADR-0009](0009-low-friction-capture.md) 继续讨论；本条不代表那些字段已经自动采集。

## 结果与取舍

- 以封面和标题帮助辨认，主体不适合抠图时保留完整画面；不得把抠图当成所有素材的必要处理。
- 地点关系应能追到标题、文案或已确认字段；同主题相关不等于同一作品或同一家店。
- 当前 13 条样例及分类写在 `index.html`，不是 LLM 或自动分类引擎的输出；没有实际接入 LLM。
- 没有封面的样例用文字占位；时间或来源缺失仍显示未知。
- 当前能用已有资料辅助人工查找，不等于已经开发原文搜索、相似推荐或永久归档。

## 如何验证 / 未决问题

下一步使用真实分享核对“输入包含什么、最终保留什么”，记录缺失和错误，不用人工整理后的样例代表自动能力。再决定是否、在哪个环节引入语义提取、识别或用户确认。

同内容合并需要什么身份依据、哪些媒体可持续保存，以及个人补充信息是否参与共同检索，均未确定。
