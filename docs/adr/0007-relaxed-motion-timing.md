# ADR-0007：分离自动浮现与主动操作的速度

- 决策状态：已接受
- 实施状态：已上线，当前动效基线
- 验证状态：已有浏览器时序检查；未形成正式感受评分或留存验证
- 建档日期：2026-09-12（历史回填）
- 决策日期：2026-09-12
- 类型：交互细化
- 路线关联：[动效减速里程碑、R5](../../ROADMAP.md)
- 替代范围：[ADR-0006](0006-ambient-memory-shuffle.md) 的初版时长 / 节奏；保留其内容组织和选择原则

## 问题与依据

用户体验初版后反馈：“从一个切换到另外一个的过程有点太快了”，会破坏产品的松弛感。初版自动和主动操作共用约 0.82 秒的前段较快缓动，底部标题还会立即换掉。

## 候选与决策

- 只延长换片间隔：每次切换仍然快，不能直接解决用户指出的过渡感。
- 把所有操作都放慢：有目标的选择也可能变迟钝。
- **采用：自动浮现慢启慢收，主动切组保持反馈；底部信息随自动切换过渡。** 用户的减速反馈授权了本轮调整，具体参数是该轮实施选择。

## 当前参数与结果

| 项目 | 当前实现 | 说明 |
| --- | --- | --- |
| 自动位置 / 大小变换 | 1.7 秒，`cubic-bezier(.38,0,.18,1)` | `is-ambient-transition` 仅在自动交接启用 |
| 常规自动调度间隔 | 随机 9–13 秒 | 从一次调度到下次触发；不是动效结束后再静止 9–13 秒 |
| 首轮调度 | 配置为 7 秒 | 程序居中、输入、悬停等暂停可能重排计时，不保证固定第 7 秒切换 |
| 主动位置变换 | 0.82 秒 | 用户点选 / 切组不套用自动慢速样式 |
| 主封面内部推近 | 9.6 秒 | 周边轻浮对应 8.8 秒 |
| 底部信息交接 | 约 0.5 秒淡出，620ms 时更新，再淡入 | 标题、缩略图与地址在同一次绘制更新；按钮仍可操作 |
| 选中后周边恢复 | 约 8 秒且满足可运行条件 | 独立于常规 9–13 秒间隔；选中项保持 |

参数以 [`b0c7e41`](https://github.com/bakeyliao-boop/Vibe/commit/b0c7e41) 为准。调慢是体验取舍，不是证明 1.7 秒为最佳值；不使用任意“松弛度分数”当证据。

## 如何验证 / 何时重看

核对自动 / 手动时长确实分离；观察卡片、密集标题和托盘是否同步；覆盖交接中途点击原文的显示和地址一致性。历史交付通过脚本语法、差异检查及浏览器时序检查：本会话当次工具输出记录自动 `transitionDuration` 为 1.7 秒、主动切组为 0.82 秒、托盘延迟换文案且无运行错误。本次仅回填这些结果，没有重新运行浏览器。

若用户仍认为“抢位”，应再看移动路径、前后层级和信息替换，而不是无限增加等待时间。新增搜索模式时，主动查找的内容应停止自动变化，见 ADR-0008。
