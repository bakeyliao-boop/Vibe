## 问题与依据

用户希望地点、类型、分享人下方的内容像手机相册小组件，有随机变化的感觉，但不是连续滚动。讨论将其具体化为：稳定画布中，一条内容浮到主位，完成后停住。用户随后明确要求按此调整。

## 候选与决策

- 连续滚动或整排轮播：用户难停留辨认，也不符合“并不是滚动”的描述。
- 自由漂浮、整屏随机重排：位置不可预测，可能妨碍点击。
- **采用：预设槽位中低频轮换视觉主位，一次主要交接一组前后内容；已选内容保留，只让周边轻微浮现。**

## 实施与边界

- 同屏最多 7 张；超过数量时其他内容会参与轮换。主焦点与用户选择分开保存。
- 自动换片不改变分组。组名条程序居中不能被误判为用户切组。
- 用户触碰后暂停，约 8 秒且没有其他暂停条件时恢复；已选项及原文链接保持一致，周边仍可变化。
- 鼠标悬停、键盘焦点、后台与减少动态等状态抑制自动换片；单条分组不自动换主位。
- 防重复只基于当前会话的近期主焦点，不代表读过状态或长期兴趣。
- 暂停当前自动任务不等于已经严格冻结所有正在执行的 CSS 位移；手指按住跨过恢复时间等边界还应补设备验收。
- 最多 7 张提升视觉容量，但在减少动态模式下其余条目缺少直接访问路径。这是明确缺口，关联 [ADR-0008](0008-browse-and-retrieval.md)，不视为最终信息可达方案。

## 速度沿革

首轮实现 `dfef05c`：一般换片间隔 6–10 秒，位移约 0.82 秒。用户指出切换太快后，ADR-0007 改为自动 1.7 秒和常规间隔 9–13 秒。这里保留初版参数用于理解迭代，不作为当前规范。

## 如何验证

观察内容是否被重新注意到，并测试选中、切视角、原文一致性、隐藏内容访问及减少动态。不能用动画停留时长直接证明收藏需求成立。
