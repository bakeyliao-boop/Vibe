# ADR-0004：选中资源后始终提供原内容入口

- 决策状态：已接受
- 实施状态：原文入口已上线；回查搜索与恢复未实现
- 验证状态：已有链接与选择一致性检查；未保证所有原文可达
- 建档日期：2026-09-12（历史回填）
- 决策日期：未记录；不晚于 2026-08-12；2026-09-12 补充交互冻结
- 类型：核心交互
- 路线关联：[R3、R5](../../ROADMAP.md)

## 问题与依据

用户明确指出：不管链接有没有过期，对选定资源都需要一个能点击跳转的入口。浏览封面只是中间步骤，用户还需要回到小红书等原平台。

## 候选与决策

- 只看封面，靠长按或隐藏菜单找链接：不符合明确入口要求。
- 根据未经验证的可达性禁用按钮：可能让原本能在 App 中打开的内容无法尝试。
- **采用：固定托盘展示当前资源和“在小红书打开原内容”按钮。** 未验证状态保留尝试打开能力。

## 结果与边界

- 封面点击承担选择；原文按钮承担外跳。两者不应让用户误解。
- 切换地点、类型、分享人时，已选资源的原链接保持一致。
- 自动浮现未选中内容时，托盘可跟随当前主内容；原文按钮按下或获得键盘焦点时暂停自动更新，避免在准备打开时换成另一条。
- 现有外跳 URL 为样例预置地址，不含完整原始分享文本；不能因此声称实现了分享短链更新、登录适配或原文恢复。
- 链接无法访问时，已有标题 / 封面可以辅助人工回查；“复制原链接、搜索原标题、相似结果”等入口尚未实现。

## 如何验证 / 何时重看

比较所选卡片、托盘标题与按钮地址；覆盖自动交接过程中按下、键盘聚焦以及切视角。真实 iPhone Safari / 原平台 App 打开行为仍需设备验证。

若未来加入异步解析、跳转回退或原文搜索，另立 ADR 或新增关联记录，明确地址和显示内容如何保持一致。
