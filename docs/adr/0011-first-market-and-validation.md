# ADR-0011：以固定玩伴的生活分享场景验证首发市场

- 决策状态：提案
- 实施状态：未招募、未正式产品发布
- 验证状态：有需求案例与竞品资料；无市场规模、留存或付费数据
- 建档 / 讨论日期：2026-09-12
- 类型：市场 / 产品定位
- 路线关联：[R6、R7](../../ROADMAP.md)

## 问题与依据

用户的萧山夜市经历说明：共同分享曾存在，之后只剩地点和内容印象，查找失败可能影响实际使用。它支持进一步测试固定玩伴需求，但一个案例不足以代表整个用户市场。

首发要选一群能方便招募、能提供真实分享并反复遇到找回场景的人，同时说明当前产品为什么值得试。

## 候选与当前建议

- 泛收藏工具人群：覆盖广，但当前功能完整性无法据此证明相对优势。
- 临时长途旅行攻略群：可能很快需要日程、预算和路线；旅行结束后的持续使用也不确定。
- **建议首测：国内经常在小红书、抖音、微信间分享生活内容，有两三位固定玩伴的人。** 招募入口可先使用同城探店、逛展和周边游；不要求每条分享都有行动意愿。

杭州及浙江周边是便于利用现有素材开始访谈的候选地区，不代表已经证明那里需求最大。年龄、性别、收入与情侣关系不设为当前已验证画像。

建议表达：“朋友发过的好东西，过阵子也找得到。” 内容仍可包含食谱、好笑的视频与其他生活灵感；市场入口不等于把产品范围锁定为旅行计划。

## 建议试验与证据口径

先考虑十组固定玩伴、连续两周使用自己的真实分享；这是上一轮建议的试验规模，不是已执行计划或行业标准。开始前另行约定样本、任务与继续推进的标准。

- 自发保存：无测试人员提醒时是否继续收内容；区分发起人与其他成员。
- 找回：目标内容是否真的找到、耗时、命中线索、原文打开结果；与原方法对照，并保留失败样例。
- 共同使用：除发起人外是否有人主动回访、查找或贡献；接受邀请不等于活跃。

优先看“每组是否有人成功找回旧内容，以及非发起人成员是否也使用”。注册量、封面停留时长、好看的口头评价不能单独作为成立证据。两周观察不足以证明长期留存，必要时延长观察，再作正式发布决定。

## 未决问题 / 重看条件

真实保存增加的步骤是否值得？是共同需求还是发起人的个人整理需求？是否有付费意愿？若无法持续保存或找回优势不成立，应先修复或收窄用途，再扩大推广。
